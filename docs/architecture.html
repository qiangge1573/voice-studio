Voice Studio 微信小程序 · 系统架构
数据流：录音采样 → 上传建音色 → 文本合成 → 播放与历史 · 引擎可插拔（XTTS / CosyVoice / Mock）
端到端流程：① 小程序录音（mp3，≤10MB）→ POST /api/voices 建音色（须勾选声音授权）→ ② POST /api/tts/synthesize 提交文本 → 后端线程池异步调引擎合成（默认火山云 few-shot 复刻，AIGC 水印）→ 前端每 1.5s 轮询任务状态 → ③ 完成后 InnerAudioContext 播放（URL 带 token），记录写入历史。视频配音：上传视频 + 台本 → 逐段合成 → ffmpeg 按时间轴混音 → 输出 mp4。
合规要点：仅允许克隆本人/已授权声音（界面强制确认）；合成结果标注「AI 合成内容」并默认开 AIGC 水印；上架需配置深度合成类服务类目并通过审核（以微信官方最新要求为准）。
